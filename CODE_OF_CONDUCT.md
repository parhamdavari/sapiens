# Code of conduct

## The short version

Be decent. Assume the other person is trying to help. Criticise the work, not the person.

## Scope

This applies to issues, pull requests, discussions, and any other space run by this project.

## Not acceptable

- Personal attacks, insults, or demeaning comments
- Harassment of any kind, public or private
- Publishing someone's private information without permission
- Sustained disruption of discussion

## A note on language

This project exists because English is a second language for many of the people using it.
Contributors write in the English they have. Correcting someone's grammar in order to
dismiss their point is not welcome here. Correcting a rule *inside the skill* for clarity
always is.

## Enforcement

Report problems by opening an issue marked `conduct` or by contacting the maintainers
privately. Reports are handled discreetly. Maintainers may edit, hide, or delete comments,
and may block accounts that keep breaking these rules.
